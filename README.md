## 🎯 Возможности

| Функция | Описание |
|:--------|:----------|
| ✅ **29 игр** | Готовый набор с картинками и описаниями |
| ✅ **Drag & Drop** | Перетаскивай картинки между тирами мышкой |
| ✅ **Кнопка ℹ️** | Сюжет + геймплей для каждой игры |
| ✅ **Свои картинки** | Добавляй любые изображения со своими названиями |
| ✅ **Смена цветов** | Меняй цвет каждого ряда (кнопка 🎨) |
| ✅ **Редактирование** | Меняй названия тиров (клик на текст) |
| ✅ **Сброс** | Возвращает стартовые 29 игр |
| ✅ **Очистка** | Удаляет все картинки одним кликом |
| ✅ **Счётчик** | Показывает общее количество картинок |
